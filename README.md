# WinFormsSuspendedAccelerationBall

## 系统性能监控与优化工具 - 半透明悬浮球版本

这是一个基于 WinForms 的系统性能监控和优化工具，以**半透明悬浮球**的形式呈现，提供实时系统信息监控和进程管理功能。

### 主要特性

#### 🎯 半透明悬浮球界面
- **悬浮球设计**: 150x150像素的圆形悬浮窗口，始终置顶显示
- **半透明效果**: 优雅的半透明渐变背景，根据CPU使用率动态变色
  - 绿色 (0-30%): 性能良好
  - 黄色 (30-60%): 正常使用
  - 橙色 (60-80%): 较高负载
  - 红色 (80-100%): 高负载警告
- **实时显示**: 球体中心显示CPU使用率百分比，底部显示内存使用率
- **自由拖动**: 鼠标左键拖动悬浮球到屏幕任意位置
- **右键菜单**: 快速访问功能
  - 查看详情
  - 一键优化
  - 进程管理
  - 退出
- **双击展开**: 双击悬浮球打开详细信息窗口

### 功能特性

#### 1. 实时信息智能同步
- **CPU 占用监控**: 实时显示 CPU 使用率，带有可视化进度条
- **内存占用监控**: 显示当前内存使用情况，包括已用/总量和百分比
- **硬件温度监控**: 显示 CPU 温度（如果硬件支持）
- **网络速度监控**: 实时显示上传和下载速度
- **一键优化**: 快速清理内存和优化系统进程

#### 2. 进程监控加速
- **实时进程监控**: 显示所有运行中的进程及其详细信息
- **智能分类**: 自动将进程分类为系统进程、浏览器、开发工具、媒体应用、办公软件、游戏等
- **进程管理**: 支持结束进程、调整进程优先级
- **自定义筛选**: 按类别筛选进程
- **详细信息**: 显示进程 ID、名称、内存占用、CPU 使用率、线程数等

### 系统要求

- Windows 10 或更高版本
- .NET 6.0 或更高版本

### 构建和运行

```bash
# 构建项目
dotnet build SystemMonitor.sln

# 运行项目
dotnet run --project SystemMonitor/SystemMonitor.csproj
```

### 技术栈

- C# / .NET 6.0
- Windows Forms
- System.Management (用于 WMI 查询)
- Performance Counters (用于系统性能监控)

### 项目结构

```
SystemMonitor/
├── Services/
│   ├── SystemMonitorService.cs    # 系统监控服务
│   ├── ProcessMonitorService.cs   # 进程监控服务
│   └── OptimizationService.cs     # 优化服务
├── MainForm.cs                     # 主窗体
├── MainForm.Designer.cs            # 窗体设计器
├── MainForm.resx                   # 窗体资源
├── Program.cs                      # 程序入口
└── SystemMonitor.csproj            # 项目文件
```

### 注意事项

- 部分功能（如硬件温度监控）需要特定硬件支持
- 某些进程操作需要管理员权限
- 建议以管理员身份运行以获得完整功能
